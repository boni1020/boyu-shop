# 波嶼 Boyu Shop

澳洲商品選物與代購網站。
以 React + TypeScript + Vite 建置，提供商品瀏覽、分類導覽與商品詳細資訊等核心功能。

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- CSS
- GitHub

---

## Getting Started

Node.js v22.23.2

### install

```bash
npm install
```

### 啟動本地端開發環境

```bash
npm run dev
```

### 打包專案

```bash
npm run build
```

# 在本地預覽打包後的正式版本

```bash
npm run preview
```
